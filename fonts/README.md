# Bundled label fonts

Unmodified Noto Sans regular and bold from [noto-fonts v20201206-phase3](https://github.com/notofonts/noto-fonts/tree/v20201206-phase3/hinted/ttf/NotoSans), under the [SIL Open Font License](OFL.txt). These cover Latin, Greek, Cyrillic and combining accents. They do not supply CJK or emoji coverage.

KaTeX fonts remain the default for ASCII diagrams and local SVGs. Noto Sans is used for Unicode diagram labels and as embedded SVG fallback. No system fonts are loaded.
